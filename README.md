# AuraTree · 頂級 p5.js 生成藝術與物理風動樹

AuraTree 是一個結合植物形態學、物理動力學與生成藝術美學的 p5.js 互動專案。本專案借鑑並融合了 GitHub 與 Creative Coding 開源社群中 **最頂級的 10 款生成樹（Generative Trees）** 之核心演算法，打破傳統直線幾何分形樹的呆板生硬感，呈現出兼具生命律動與詩意氛圍的視覺盛宴。

---

## 🌟 核心融合之 10 大 GitHub 經典演算法

1. **空間佔用生長（Space Colonization - Coding Train CC_017）**：散佈冠層吸引點，形成繁茂有機、富含體積感的自然樹冠。
2. **植物學形態模型（Weber-Penn - dgreenheck/ez-tree）**：主幹基座天然漸展擴張（Root Flare）、自然粗細過渡與多階層生長比例。
3. **連續拓撲網格平滑（supereggbert/proctree.js）**：消除關節硬折角，展現平滑分叉的自然分枝。
4. **隨機文法生成（Stochastic L-System - trebeljahr/fractal-garden）**：種子基因隨機化，無限演化不同生長姿態。
5. **貝塞爾風力落櫻（jackcruden/sketches/blossom）**：三次貝塞爾曲線（Cubic Bézier）刻畫蒼勁主幹，末端飄曳落櫻粒子。
6. **柏林噪聲滄桑樹皮（Perlin Noise - jvillegasd）**：噪聲場調變樹幹彎曲與樹瘤微擾，賦予古木自然年輪感。
7. **彈簧阻尼風動物理（Physics Damping - p5.js Trees in the Wind）**：枝條具備剛度與質量，可隨環境風力與滑鼠微掠產生鏈式搖曳與彈性回彈。
8. **阿凡達靈魂發光樹（Bioluminescent Glow / Bloom Shader）**：Canvas 多重陰影疊加與發光光暈，搭配發光孢子與螢火蟲夜舞。
9. **水彩微暈染（Pappus Generative Art）**：多層半透明葉片與花瓣交疊，營造柔和細緻的東方水墨丹青韻味。
10. **四季時序狀態機（Four Seasons Lifecycle）**：春櫻、夏綠、秋楓、靈魂之樹、寒冬霜雪五大主題一鍵流暢切換。

## 🎮 互動功能與操作指南

- **🌸 主題切換 Dock**：
  - **春櫻爛漫 (Sakura Dream)**：暮色微風、粉櫻簇擁、飄落櫻吹雪。
  - **盛夏古榕 (Emerald Oak)**：翠綠繁盛、老樹盤根、晨曦林間微粒。
  - **金秋落楓 (Golden Autumn)**：金色楓紅、瑟瑟秋風、漫天旋轉落葉。
  - **靈魂之樹 (Avatar Spirit)**：曜石暗夜、螢光青紫霓光、輕盈向上浮動之發光孢子。
  - **寒冬霜雪 (Winter Frost)**：銀裝素裹、純白積雪、靜謐飛雪。
- **🌱 重新破土生長 (Re-Grow)**：觀賞樹木自幼苗破土、主幹伸展、側枝抽條至繁花怒放的平滑生長動畫。
- **🎲 隨機基因形態 (Random Seed)**：生成姿態各異、獨一無二的專屬樹木形態。
- **🎛️ 物理與形態微調面板**：
  - **樹木高度**：縮放主幹與總體尺寸。
  - **分枝曲折度**：控制枝條彎曲弧度與枝椏開合度。
  - **繁茂密度**：調節葉簇與花瓣群集量。
  - **環境風力**：無風、微風至強風的動態頻率。
  - **枝條彈性**：調整枝梢受風受力後的彈簧回彈幅度。
  - **粒子數量**：控制落花/落葉/雪花/發光孢子密度。
- **🖱️ 滑鼠交互擾動**：在畫布上移動滑鼠靠近樹冠，可即時推動風力場，枝葉隨之柔順擺動。
- **📸 高畫質作品匯出 (PNG)**：一鍵保存當前形態的高解析度數位藝術作品。
